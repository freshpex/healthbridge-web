# HealthBridge Web

React + TypeScript + CSS web experience for HealthBridge.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Commands

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

## Demo Users

Use any seeded backend credential or one of the built-in persona buttons on `/signin`. Password for seeded users: `Password123!`.

The hero uses a real clinical photo from Unsplash. The generated product concept used during implementation is saved under the Codex generated images directory and can be copied into `src/assets/images` for design review archives.
